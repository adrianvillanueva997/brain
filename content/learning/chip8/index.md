# Learning CHIP-8 Emulator Development in Rust

This is an agent-guided course for building a CHIP-8 emulator in Rust while understanding the machine it interprets.

## Course map

1. [[lessons/0001-machine-model-and-fetch|01 — The machine model and fetch]]
2. CPU state and opcode decoding
3. The display and XOR drawing
4. Control flow, stack, and subroutines
5. Timers, keyboard, and execution timing
6. ROM loading, clients, and verification

## Workspace

1. [[MISSION|Mission]] — why this course exists and what success means
2. [[RESOURCES|Resources]] — trusted references used to ground lessons
3. [[reference/chip8-machine|CHIP 8 machine reference]] — compressed facts for review
4. [[NOTES|Teaching notes]] — preferences and course decisions
5. `learning-records/` — durable insights added after demonstrated understanding

## How to use this

Read one lesson, answer its retrieval prompt without looking back, then implement the smallest matching change in the emulator repository. Ask follow-up questions whenever a step is unclear.
