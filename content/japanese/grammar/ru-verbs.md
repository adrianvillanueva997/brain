る-verbs always end in **〜る**. One rule for everything.

## Dictionary form

Drop る → add nothing (that's the plain form).

| Verb | Meaning |
|------|---------|
| 食べる (たべる) | to eat |
| 見る (みる) | to see |
| 起きる (おきる) | to wake up |
| 寝る (ねる) | to sleep |
| 教える (おしえる) | to teach |
| 出る (でる) | to leave / to exit |
| 着る (きる) | to wear |

## Present affirmative

Drop る → add **ます** (polite) / dictionary form (plain).

| Plain | Polite | Meaning |
|-------|--------|---------|
| 食べる (たべる) | 食べます (たべます) | eat |
| 見る (みる) | 見ます (みます) | see |
| 起きる (おきる) | 起きます (おきます) | wake up |
| 寝る (ねる) | 寝ます (ねます) | sleep |
| 教える (おしえる) | 教えます (おしえます) | teach |
| 出る (でる) | 出ます (でます) | leave |
| 着る (きる) | 着ます (きます) | wear |

## Present negative

Drop る → add **ない** (plain) / **ません** (polite).

| Plain | Polite | Polite positive | Meaning |
|-------|--------|-----------------|---------|
| 食べない (たべない) | 食べません (たべません) | 食べます | eat |
| 見ない (みない) | 見ません (みません) | 見ます | see |
| 起きない (おきない) | 起きません (おきません) | 起きます | wake up |
| 寝ない (ねない) | 寝ません (ねません) | 寝ます | sleep |
| 教えない (おしえない) | 教えません (おしえません) | 教えます | teach |
| 出ない (でない) | 出ません (でません) | 出ます | leave |
| 着ない (きない) | 着ません (きません) | 着ます | wear |

## How to tell る-verbs from う-verbs

る-verb: vowel before る is **e** or **i**.

| る-verb | う-verb (trap!) |
|---------|-----------------|
| 食べる (たべる) | 帰る (かえる, to return) — e + る? No, it's う-verb |
| 見る (みる) | 走る (はしる, to run) — i + る? No, it's う-verb |
| 着る (きる, to wear) | 切る (きる, to cut) — same reading! 切る is う-verb |

Rule of thumb: if the vowel before る is short i/e and the verb doesn't have a single-kanji stem that's also a common う-verb, it's probably る-verb. Exceptions exist — learn them as you go.
