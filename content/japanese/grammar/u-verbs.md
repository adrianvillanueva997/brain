う-verbs end in any **〜u** kana: 〜う, 〜く, 〜す, 〜つ, 〜ぬ, 〜ぶ, 〜む, 〜る, 〜ぐ.

The ending changes depending on what follows. This is the "5-stage" (五段) verb group.

## Dictionary form

| Verb | Meaning |
|------|---------|
| 書く (かく) | to write |
| 話す (はなす) | to speak |
| 待つ (まつ) | to wait |
| 読む (よむ) | to read |
| 遊ぶ (あそぶ) | to play |
| 死ぬ (しぬ) | to die |
| 買う (かう) | to buy |
| 泳ぐ (およぐ) | to swim |
| 帰る (かえる) | to return (trap: る-ending but う-verb) |
| 走る (はしる) | to run (trap: る-ending but う-verb) |
| 切る (きる) | to cut (trap: る-ending but う-verb) |

## Present affirmative polite

Change the last **u**-kana → **i**-equivalent → add **ます**.

| Dict | Stem (u→i) | Polite | Meaning |
|------|-----------|--------|---------|
| 書く (かく) | かき | 書きます (かきます) | write |
| 話す (はなす) | はなし | 話します (はなします) | speak |
| 待つ (まつ) | まち | 待ちます (まちます) | wait |
| 読む (よむ) | よみ | 読みます (よみます) | read |
| 遊ぶ (あそぶ) | あそび | 遊びます (あそびます) | play |
| 死ぬ (しぬ) | しに | 死にます (しにます) | die |
| 買う (かう) | かい | 買います (かいます) | buy |
| 泳ぐ (およぐ) | およぎ | 泳ぎます (およぎます) | swim |
| 帰る (かえる) | かえり | 帰ります (かえります) | return |
| 走る (はしる) | はしり | 走ります (はしります) | run |
| 切る (きる) | きり | 切ります (きります) | cut |

## Present negative plain

Change the last **u**-kana → **a**-equivalent → add **ない**.

| Dict | Stem (u→a) | Plain neg | Meaning |
|------|-----------|-----------|---------|
| 書く (かく) | かか | 書かない (かかない) | don't write |
| 話す (はなす) | はなさ | 話さない (はなさない) | don't speak |
| 待つ (まつ) | また | 待たない (またない) | don't wait |
| 読む (よむ) | よま | 読まない (よまない) | don't read |
| 遊ぶ (あそぶ) | あそば | 遊ばない (あそばない) | don't play |
| 死ぬ (しぬ) | しな | 死なない (しなない) | don't die |
| 買う (かう) | かわ | 買わない (かわない) | don't buy |
| 泳ぐ (およぐ) | およが | 泳がない (およがない) | don't swim |
| 帰る (かえる) | かえら | 帰らない (かえらない) | don't return |
| 走る (はしる) | はしら | 走らない (はしらない) | don't run |
| 切る (きる) | きら | 切らない (きらない) | don't cut |

> **〜う → 〜わない**: 買う becomes 買**わ**ない (not 買**あ**ない). Same for 言う → 言わない, 会う → 会わない.

## Present negative polite

**ません** attaches to the i-stem (same as polite affirmative):

| Dict | Polite neg | Meaning |
|------|-----------|---------|
| 書く (かく) | 書きません (かきません) | don't write |
| 話す (はなす) | 話しません (はなしません) | don't speak |
| 待つ (まつ) | 待ちません (まちません) | don't wait |
| 読む (よむ) | 読みません (よみません) | don't read |
| 遊ぶ (あそぶ) | 遊びません (あそびません) | don't play |
| 死ぬ (しぬ) | 死にません (しにません) | don't die |
| 買う (かう) | 買いません (かいません) | don't buy |
| 帰る (かえる) | 帰りません (かえりません) | don't return |

## う-verbs vs る-verbs cheat sheet

| | る-verb | う-verb |
|---|---|---|
| ます | drop る → +ます | u→i → +ます |
| ない | drop る → +ない | u→a → +ない |
| Rule | same for everything | ending changes by the next suffix |

**五段 (godan) means "5 stages"** — the vowel shifts through a, i, u, e, o depending on what attaches. Once you see the pattern it's consistent for every う-verb.
